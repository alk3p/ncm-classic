## Login

[music.163.com](https://music.163.com/) 登录后 F12 > Application，左侧 Cookies 展开选中，搜索 `MUSIC_U` 复制粘贴至对话框即可。

该 cookie 有效期一年，请勿明文保存。本软件使用 [Credential Manager](https://support.microsoft.com/en-us/windows/security/credential-manager-in-windows) 或 [GNOME Keyring](https://wiki.gnome.org/Projects/GnomeKeyring) 管理您的凭据。
